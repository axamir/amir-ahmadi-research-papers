## Zenodo/GitHub note

Zenodo can archive enabled GitHub repositories when new GitHub releases are created. Because this repository contains multiple research papers, archiving the entire repository for a DOI intended to identify only this paper can create ambiguity. Before enabling automatic release ingestion, decide whether the DOI should identify:

- the entire `amir-ahmadi-research-papers` repository/version; or
- this individual paper and its evidence package.

For a paper-specific DOI, a dedicated archival deposit of this paper package is the cleaner metadata model unless the repository's release/tag strategy explicitly isolates this work.
