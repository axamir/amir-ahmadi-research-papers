# Evidence Archive

This directory is intended to preserve the de-identified source evidence used in the working paper.

## Planned evidence classes

- iPhone Screen Time screenshots
- Mac Screen Time screenshots
- Battery Usage screenshots
- Extracted day-level values
- External space-weather source records

## Evidence handling rules

1. Preserve original screenshots whenever possible.
2. Redact irrelevant personal identifiers, notifications, account details, private URLs, financial information, or other unrelated sensitive material before public release.
3. Do not modify numerical values used in the analysis.
4. Keep a manifest linking each public evidence file to device, observed date, capture date, metric, and any redaction performed.
5. Do not treat Apple Screen Time categories as direct measurements of cognitive state.
6. Preserve evidence that contradicts the initial hypothesis.

## Traceability target

The intended audit chain is:

**raw screenshot → manifest → extracted dataset → figure/table → interpretation**

The public archive should make it possible for a reader to trace reported behavioral numbers back to their source evidence.

## Publication status

Raw screenshots have not yet been published in this directory. They should be reviewed and de-identified before upload.
