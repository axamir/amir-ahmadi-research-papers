# Meta-Research Layer — We Are Code That Breathes

**Parent paper:** `ARP-WCB-2026-01` — *We Are Code That Breathes*  
**Parent release state:** RC v0.3 — closed publication package  
**Meta-layer status:** post-publication research note / forensic reconstruction  

## Purpose

This directory preserves a second-order investigation that began only after the parent paper had been completed.

The motivating question was deliberately simple:

> **What exactly was happening in the world — and in the observable sky — when the original LinkedIn post was published?**

The inquiry was not designed to search for validation, hidden meaning, causality, or cosmic significance. It began as timestamp reconstruction and developed into a study of unrelated simultaneous events, historical anniversaries, pre-existing internal language, and the provenance of discovering apparent coincidences.

The central methodological rule is:

> **Coincidence is not causality.**

A second rule follows from it:

> **A coincidence can become more interesting without becoming more true.**

## Why this is separate from the paper

Nothing in this directory changes the scientific claims, status, or release state of RC v0.3.

The temporal investigation is **not evidence for PRCEP, the relational/trajectory hypothesis, consciousness, biological equivalence, or any other scientific claim in the parent paper**.

It is preserved because the sequence of discovery itself is relevant to provenance:

1. the internal Echo / Living Signal vocabulary existed in archived material;
2. the LinkedIn post was published;
3. public discussion materially transformed the research question;
4. the paper was constructed and closed;
5. only afterward was the publication timestamp investigated;
6. only afterward were external historical and astronomical coincidences noticed.

This order matters because it distinguishes retrospective discovery from deliberate symbolic design.

## Evidence classes

Every item should be assigned one of the following:

- **FACT** — directly supported by a primary or high-quality source.
- **DERIVED** — calculated from supported facts; derivation must be reproducible.
- **PREDICTED** — model forecast or scheduled event, not equivalent to an observed event.
- **HISTORICAL COINCIDENCE** — independently documented event sharing date/time structure without causal claim.
- **INTERPRETATION** — authorial reading or conceptual juxtaposition, never presented as physical evidence.
- **EXCLUDED** — investigated but removed because evidence was insufficient, misleading, or unnecessary.
- **UNRESOLVED** — potentially recoverable, but not yet supported strongly enough for publication.

## Narrative principle

The public-facing version should read as an investigation, not as a list of signs:

> I was not looking for meaning. I was looking for a timestamp.

The reader should encounter each finding in the order it was investigated, including failed searches and discarded claims. This preserves curiosity without converting pattern recognition into pseudo-explanation.

## Publication boundary

The intended public sequence is:

1. publish the parent research paper and Research Hub link;
2. separately publish the meta-research narrative as **research on the research**;
3. keep the two epistemically distinct.

The meta-research may be visually playful, mysterious, or exploratory, but the evidence ledger must remain conservative.
