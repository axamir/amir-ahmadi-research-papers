## Timestamp note

The export independently supports only the **minute-level publication time: 5:55 PM local time**. The second-level timestamp used in the temporal investigation is **derived** from the numeric activity identifier embedded in the original LinkedIn post URL (`7493311627023433728`) using the observed high-bit millisecond convention (`activity_id >> 22`). That derivation yields:

**2026-08-12 14:25:10.880 UTC**  
**2026-08-12 17:55:10.880 IRST (UTC+03:30)**

LinkedIn does not provide a public platform specification in the sources collected here that formally guarantees this decoding convention. Therefore the investigation treats:

- **17:55 local / 14:25 UTC** as platform-supported at minute precision;
- **14:25:10.880 UTC** as a reproducible but non-officially-documented derived timestamp.

## Integrity boundary

This snapshot records what the supplied export reports. It does not claim that:

- an impression equals a unique reader;
- a reached member read the full post;
- a repost is endorsement;
- a comment is peer review;
- a demographic affiliation means an organization endorsed or reviewed the work.
