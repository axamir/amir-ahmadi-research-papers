# AI Mediation Disclosure

Generative AI materially assisted this research workflow through discussion analysis, drafting, translation, reframing, comparison, structural organization, counterargument generation, claim auditing, and synthesis.

Model output is not treated as independent empirical evidence. Model participation does not establish consciousness, authorship, responsibility, or intellectual priority. Factual and literature-dependent claims require evidence external to model generation.

Where known and relevant, releases should preserve model/product identity, date, context or memory status, tool access, and uncertainty about unavailable configuration details.

Git history is evidence of artifact versioning, not complete proof of intellectual provenance. PRCEP therefore preserves uncertainty rather than treating technical metadata as infallible.
