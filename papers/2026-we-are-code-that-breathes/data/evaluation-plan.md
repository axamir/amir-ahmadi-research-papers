# PRCEP Evaluation Plan

PRCEP is not considered validated by the construction case.

## Primary comparison
Compare a provenance-rich representation with a matched-information control that contains equivalent substantive information but no explicit claim-transition structure.

## Outcomes
- origin attribution accuracy
- transition reconstruction accuracy
- correction visibility
- independence discrimination
- model-mediation transparency
- current-state fidelity
- evidence-link completeness

## Cost measures
- annotation time
- storage overhead
- evaluator reading time
- maintenance burden
- privacy/redaction burden

## Failure criteria
PRCEP should be simplified or rejected if reconstruction gains are negligible, disappear under matched-information controls, or are too small relative to maintenance cost.

The stronger trajectory hypothesis should be weakened if ordered persistent interaction provides no measurable advantage after information quantity and content are controlled.
