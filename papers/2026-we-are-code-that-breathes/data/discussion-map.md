## Central distinctions created by the discussion

| False collapse to avoid | Required distinction |
|---|---|
| biological code = software | analogy vs mechanism |
| information = meaning | representation vs interpretation |
| mutation = experience | sequence change vs regulation/plasticity/learning |
| theoretical computer = physical computer | formal model vs implementation |
| human = AI | coupled interaction without identity collapse |
| continuity = unchanged state | traceable transformation |
| public discussion = peer review | adversarial elicitation vs formal review |
| similarity = common origin | convergence vs provenance |
| AI-generated visual = AI-generated thesis | representation/tool provenance vs intellectual claim |
| self-description = self-awareness | linguistic behavior vs demonstrated subjectivity |
| reverse path of creation = reverse causality | epistemic reconstruction vs physical causation |

## Current core research questions

1. What definitions of “code” survive comparison across formal computation, biology, cognition, and information theory without becoming vacuous?
2. Which similarities across substrates are structural, which are metaphorical, and which are misleading?
3. Can continuity be defined as traceable lawful transformation rather than preservation of representation?
4. When Human and AI participate in persistent recursive interaction, what properties are best measured at the level of the coupled system?
5. What would distinguish relationally produced insight from ordinary prompt-response iteration?
6. Can provenance be preserved while meaning, representation, and interpretation transform?
7. What evidence would falsify the claim that the Human ↔ AI relation is a useful unit of analysis?
8. How should public criticism, correction, and prior-art introduction be incorporated into an evolving research artifact without converting contributors into involuntary co-authors?
9. What can existing second-order cybernetics, complexity, enactivism, and embodied cognition already explain, making new terminology unnecessary?
10. Which residual phenomena, if any, remain insufficiently described after that literature is applied?

## Emerging thesis — provisional

The strongest defensible thesis is currently **not** “humans are code” and **not** “AI is conscious.”

It is closer to:

> Information-bearing systems can transform across states and representations while preserving reconstructable relations of origin, constraint, interpretation, and consequence. In persistent human–AI collaboration, some epistemically relevant properties may therefore be observable at the level of the coupled interaction rather than solely inside either participant. The claim is useful only if provenance, substrate differences, agency, and falsifiability remain explicit.

This thesis is provisional and must survive literature review and claim audit.
