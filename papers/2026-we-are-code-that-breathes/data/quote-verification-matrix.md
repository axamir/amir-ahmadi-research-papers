# Quote & Ordering Verification Matrix

**Document:** ARP-WCB-2026-01  
**Purpose:** distinguish exact captured quotations from summaries and unresolved chronology before release.

## Verification statuses

- **Q-VERIFIED-WORKING:** exact text is preserved in the working record used to construct this artifact; external permalink/timestamp may still be missing.
- **Q-SUMMARY:** contribution is currently paraphrased and must not be typeset as a direct quotation.
- **Q-PARTIAL:** exact fragment is preserved but not the full source message.
- **ORDER-RELATIVE:** relative sequence is known from the working record, but exact timestamp is not archival-grade.
- **ORDER-EXACT-PENDING:** exact timestamp is visible in a source artifact but has not yet been normalized into the release record.

## Author-side public responses

The five-part response to Clemente is currently represented as a research-content map rather than a full verified transcript. Until the exact public reply text is re-opened and checked, the release should label it **reconstructed summary of the response trajectory**, not a verbatim appendix.

The same rule applies to other author replies that were drafted or translated during the working process but are not presently linked to an independent public artifact.

## Edited and deleted content

- A participant comment marked “edited” should retain that status if visible in the source record.
- If only the edited state survives, do not infer the pre-edit wording.
- Deleted material may be described only where a reliable preserved artifact exists.
- Absence from the current platform view is not proof that a statement never existed.

## Main-paper quotation policy

The main manuscript should prefer concise paraphrase over long social-media quotations. Direct quotations should be reserved for cases where wording itself materially caused the transition.

This reduces copyright, context, and endorsement risk while preserving the full research effect in the evidence layer.

## Archive release gate

A quotation may be marked archival-verified only when all applicable fields are recorded:

`contributor → exact text → source artifact → timestamp/order → edited state → verification date → analyst`.

Until then, the strongest permitted status is **verified working record**, not platform-verified archival transcript.
