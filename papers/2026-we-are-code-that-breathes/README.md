## What this paper is

The project began with the public question **“What if code did not begin with computers?”** and the rhetorical phrase **“We are code that breathes.”** Instead of protecting the initial metaphor, the study preserves how criticism, correction, prior-art discovery, independent conceptual convergence, model mediation, and versioned synthesis changed what could responsibly be claimed.

The resulting methodological object is **PRCEP — Provenance-Preserving Relational Claim Evolution Protocol**, an application-level protocol candidate for recording material claim transitions across human, generative-model, public-discussion, literature, and artifact-version boundaries.

This is a **protocol-construction and case-demonstration study**, not a validation study. PRCEP remains subject to independent evaluation.

## Publication boundary

This paper does **not** claim that humans are literally software, DNA is computer code, ordinary experience rewrites DNA sequence, present LLMs are conscious, provenance was invented here, relational cognition originated here, public discussion is peer review, or conceptual similarity proves common lineage.

Its narrower question is:

> **Can the becoming of a claim itself be made auditable?**

## Core research principles

1. **Provenance before synthesis.** Influence remains distinguishable from ownership, derivation, endorsement, and authorship.
2. **Correction is evidence.** Superseded claims remain reconstructable without remaining current.
3. **Metaphor is not mechanism.** Rhetorical comparison is separated from scientific equivalence.
4. **Public discussion is not peer review.** It is treated as a heterogeneous conceptual challenge record.
5. **Similarity is not lineage.** Independent convergence is preserved as independent convergence.
6. **Model output is not independent evidence.** Material AI mediation is disclosed while factual claims remain externally accountable.
7. **Auditability is not truth.** A reconstructable claim can still be false.

## Current scientific status

The English conceptual manuscript, aligned Persian edition, literature boundary, citation alignment, provenance policy, model-mediation record, adversarial review, publication metadata, and Research Hub integration are freeze-ready.

The principal unresolved scientific step is **external evaluation**. The proposed test compares a provenance-rich condition with a matched-information control and measures origin attribution, transition reconstruction, correction visibility, independence discrimination, model-mediation transparency, current-state fidelity, evidence-link completeness, and maintenance cost.

If PRCEP does not materially improve reconstruction relative to its cost, it should be simplified or rejected.

## Version and correction policy

Git history preserves artifact versions but is not treated as complete proof of intellectual provenance. Material corrections should be made through versioned amendments. Historical model configuration, source metadata, or public-thread details that cannot be recovered must remain explicitly uncertain rather than reconstructed from memory.

Public contributors named in the evidence layer are contributors to the documented trajectory, not co-authors or endorsers unless separately agreed.
