## Registration rule

For each real run:

1. assign a non-identifying run ID;
2. record the exact stimulus/material manifest;
3. preserve the raw participant wording in a separate de-identified run artifact;
4. produce a blinded scoring copy before revealing condition mapping to the scorer where practical;
5. register exclusions/deviations without deleting the run;
6. never replace missing human data with AI-generated responses.

## Repository privacy note

This repository is a public research record. Do not commit names, email addresses, IP addresses, private messages, consent signatures, compensation/payment details, or other direct identifiers. If such administrative records are required, store them outside the public repository under appropriate access controls.
