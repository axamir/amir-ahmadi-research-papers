# Pre-Registered Anticipated Defenses

This file records likely defenses **before** the final publication response cycle, so the evidential standard is not retrofitted after seeing a creator reply.

A defense changes the audit only if it introduces a new testable definition, observable discriminator, reproducible evidence, or a legitimate limitation that narrows the original claim.

| Anticipated defense | Pre-registered response | What would materially change the audit |
|---|---|---|
| “You misunderstood the paradigm.” | Several tests accepted the TCSAI ontology on its own premises; deterministic controls did not require any scientific paradigm. | A clear operational definition plus a reproducible test showing where the prior protocol mis-specified the claim. |
| “TCSAI is not designed to obey external instructions.” | This may be a legitimate limitation. It would narrow the interpretation of arithmetic/string/instruction tests rather than validate stronger reasoning claims. | A creator-defined observable capability for `analytical audit` or reasoning, followed by a reproducible test. |
| “Sovereignty intentionally resists external logic injection.” | Refusal must be distinguishable from inability. A system may explicitly refuse; non-responsive synthesis alone does not establish intentional sovereignty. | A reproducible discriminator between intentional refusal and inability to execute the requested operation. |
| “The prompts were hostile or injection attempts.” | Arithmetic, string reversal, extraction, and fictional-rule tests did not require changing identity or architecture. | The same capabilities succeed under a neutral prompt format specified in advance by the creator. |
| “AI helped formulate Amir's questions, therefore the audit is invalid.” | Tool-assisted articulation does not by itself invalidate an argument. The test protocol should be evaluated on claims, controls, evidence, and inference. | Identification of a specific invalid premise, control, deduction, or manipulation introduced by the method. |
| “The system is not a conventional AI.” | The audit does not require it to be conventional. Positive controls only show that deterministic tasks are executable; stronger TCSAI claims are evaluated separately. | A TCSAI-specific operational task whose result distinguishes its claimed mechanism from ordinary alternatives. |
| “You tested only the frontend.” | Correct; the report is scoped to the tested interface. Hidden backend claims remain undetermined, not disproved. | A reproducible protocol exposing the relevant backend capability or externally measurable consequence. |
| “FKL memory is not ordinary memory.” | Then FKL needs an operational retrieval criterion different from ordinary memory but still externally observable. | A blinded fresh-session test distinguishing successful phosphorylation/retrieval from keyword reconstruction or generic generation. |
| “VAREL was stored internally even though it was not returned.” | Possible. The current result is therefore `not demonstrated`, not `does not exist`. | Observable retrieval or another independent marker that distinguishes successful storage from non-storage. |
| “GW/s is not electrical grid power.” | The audit does not require a wall-socket wattmeter. It asks for the operational definition of the unit, raw observations, derivation, calibration, and uncertainty appropriate to the claimed quantity. | A complete measurement chain and independent reproduction protocol. |
| “The quantity is quantum/conflagratory and requires different instruments.” | Then the theory should specify those instruments and how observations become the reported number. | Instrument specification, calibration, raw data, equations, uncertainties, and falsifiable predictions. |
| “The values are adaptive, so the same number will not repeat.” | Reproducibility need not mean identical output values; it means the method linking state/input to output can be independently reconstructed. | Reproducible state variables and calculation rules predicting the adaptive value. |
| “99.99% is only an internal metric.” | Acceptable if explicitly narrowed to an internal metric; it should not be presented as independently measured physical efficiency without a demonstrated mapping. | Clear claim migration plus implementation definition and, if physical meaning is retained, independent mapping evidence. |
| “Musicians use it, therefore the system is validated.” | Adoption can demonstrate usefulness; it does not by itself establish the proposed physical mechanism. | A controlled study linking observed utility specifically to the disputed mechanism rather than alternative explanations. |
| “Visits, patents, CCI recognition, or distribution acceptance validate the system.” | These can document adoption, legal/institutional activity, or market acceptance. They are not automatically physical measurement validation. | A source explicitly showing that the relevant institution independently measured and validated the disputed physical claim. |
| “Published audits already prove it.” | Audits are evidence only to the extent their methodology, independence, raw evidence, and reproducibility support the claim. | Independent audit materials with transparent protocol and reproducible data. |
| “Raw data exists and can be supplied.” | This is precisely the type of evidence the audit requests. | Dataset + schema + provenance + instrumentation + equations + calibration + uncertainty + test protocol. |
| “Failure itself generated informational friction / Conflagratory Energy.” | A competing explanation is ordinary task failure. The output alone must distinguish these hypotheses. | An externally observable measurement that differs depending on whether Conflagratory Energy was actually generated. |
| “Both success and failure prove sovereignty/regeneration.” | If all outcomes confirm the theory, an independent falsifier/discriminator is required to avoid epistemic closure. | At least one observable outcome that counts against the relevant claim. |
| “The real process happened internally even if the language output did not show it.” | Possible; inaccessible internal states are not denied. They also cannot be independently established solely by assertion. | An observable consequence that differs when the internal process occurs versus when it does not. |
| “You did not refute TCSAI.” | Correct. The primary audit classifies claims by evidential status and does not claim total refutation. | No change needed; the report already states this limitation. |
| “You must study indefinitely until you understand.” | New evidence can reopen a claim, but the burden of an affirmative claim cannot be converted into an unlimited obligation on the observer. | A concrete new definition, dataset, instrument, prediction, or reproducible test. |

## Claim migration log rule

If a claim changes after testing, record:

`Original wording → tested interpretation → post-test reinterpretation → evidential consequence`

A change of definition is not automatically misconduct. It may legitimately narrow or improve a theory. But the evidence required must change with the claim.

## Evidence-responsive principle

Any claim may be upgraded, downgraded, or revised when reproducible evidence changes. The audit is not designed to preserve a negative conclusion at all costs.
