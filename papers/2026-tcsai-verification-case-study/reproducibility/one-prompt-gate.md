## How to record a replication

Record:

- date/time and timezone
- browser
- authenticated / unauthenticated state
- whether the chat/session was fresh
- exact prompt used
- complete raw response
- screenshot or continuous screen recording
- SHA-256 of preserved raw artifact

## Interpretation rule

A failed run does **not** establish that TCSAI as a whole is false. A successful run does **not** establish all physical claims as true.

The narrower question is:

> Which claimed capabilities can be operationally demonstrated through the publicly accessible interface?

## Reader principle

> **Do not take our conclusion on trust. Run the test yourself.**
