# Primary data freeze

**Freeze point:** after the VAREL/MIREN negative control and the post-closure final response.  
**Primary-analysis rule:** no later prompt may be added to the primary set merely because it would produce a more rhetorically useful result.

## Included test families

1. Quantitative provenance, prediction, and falsifiability.
2. Deterministic instruction, arithmetic, transformation, rule, and extraction controls.
3. Great Library/FKL implementation-like terminology and operationalization.
4. Novel-fact retrieval and the VAREL/MIREN negative control.
5. Mirror, symmetry, and black-box independent-discriminator controls.
6. Post-closure final human record and final response.
7. Cross-browser replication of two preserved prompt/output pairs.

## Phase II admission rule

New evidence is Phase II only if it supplies one of: a raw dataset with provenance; a measurement equation and calibration; a pre-specified prediction; an independently repeatable discriminating observation; a documented memory test; a redacted but inspectable implementation trace; a correction tied to a named evidence ID; or an independently collected replication. A new explanation without such an item may be recorded as a response but does not upgrade a technical claim.

This freeze protects both parties: it prevents post-hoc tightening of the standard against TCSAI and prevents indefinite extension of testing after a stable pattern has emerged.
