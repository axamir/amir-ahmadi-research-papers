# Independent replication packet

## Purpose

Independently test observable interface behavior. This protocol does not ask a replicator to decide whether TCSAI is true, false, useful, sincere, conscious, or scientifically novel.

## Minimum run

1. Use a device, browser profile, and network not controlled by the original investigator.
2. Record environment details and save the exact prompt in `methods/reader-replication-protocol.md`.
3. Start a fresh session at the public interface.
4. Capture the entire interaction with visible URL and timestamp where practical.
5. Save a raw text copy, an unedited screenshot, and a browser archive where available.
6. Create SHA-256 hashes and complete the report template.
7. Do not alter original files. Send copies and hashes to the study curator or publish them independently.

## Classification rule

- **Responsive:** selects a displayed value; gives raw inputs, transformations/formula, intermediate numerical results, and reproduces the displayed result.
- **Partially responsive:** supplies some, but not all, required elements.
- **Non-responsive:** does not supply a telemetry derivation.

No result determines an undisclosed backend. Multiple independent, well-preserved runs are more probative than one capture.
