# Quotation and privacy audit

## Audit result

The imported Safari WebArchive is valid as a preserved archive of the public `https://neurosapiens-tcsai.com/chat` page at capture time. Its main HTML identifies that URL and bundles page assets. It does **not** by itself supply a complete, independently extractable transcript of every test exchange or any LinkedIn post/comment thread.

Accordingly, the public release must apply the following rules.

| Material | Public status | Rule |
|---|---|---|
| Exact T-02 prompt and paired output | Eligible | Both texts are preserved in the case-study record; retain verbatim with environment/limitation labels. |
| Great Library self-description and operational follow-ups | Eligible with source label | Present as an interface response preserved by the documented session; do not claim code-level confirmation. |
| T-01, VAREL/MIREN, Mirror, symmetry, and black-box summaries | Eligible as summarized evidence only | Retain their evidence-status qualifier; do not put quotation marks around incomplete source text. |
| Amir’s original LinkedIn post | URL-only | Do not quote until a full dated capture is supplied. |
| Tony’s public posts | Conditional | Quote only clauses preserved in full contemporaneous transcript and mark as “reported public post”; otherwise summarize or remove. |
| Ashley comment and Tony reply | Conditional | Omit from main manuscript unless full thread capture is supplied; a chronology note may remain without interpretation. |
| Direct messages / screenshot exhibits | Private by default | Do not publish original PNGs or full text. Use only a short necessary, redacted excerpt after manual author review. |
| RAW-001 WebArchive / RAW-002 recording | Private by default | Publish hashes and protocol, not files, unless a separate privacy/rights review authorizes release. |
| DER-002 visual PDF | Private by default | Do not publish in full because it can reproduce private/interface-session material. Use a redacted crop only if indispensable. |

## Public-safe revision applied for this release

The public manuscript uses a non-identifying procedural summary for the existence of a private exchange and removes unverified conditional public-post quotations. A future version may add public-record citations only after full capture verification. This is a release edit, not an evidentiary downgrade.

## Privacy conclusion

No raw private material is authorized for public release by this audit. The reader-replication protocol, claim ledger, methods, and public-safe summary can be released without it. A future public exhibit must be the minimum necessary excerpt, visibly redacted, and derived from a named original with a hash reference.
